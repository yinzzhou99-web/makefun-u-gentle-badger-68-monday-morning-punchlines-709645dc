# Monday Morning Punchlines

One joke about Monday mornings — the week as a subscription nobody signed up for, renewing weekly with the cancel button greyed out.

## Entry

`main.py` writes one joke to `/output/entry.txt`:

> Monday is the one subscription I never signed up for, yet it renews every week and the cancel button is greyed out.

Standard library only, no network, no third-party packages.
